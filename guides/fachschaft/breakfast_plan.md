## Notes
- Remaining unopened non-perishable food - can be stored in SC room. → ONLY if it has a long period before perishing!!! don't buy much more than you think will be consumed in 1 breakfast!
- Remaining opened and/or perishable food - can be taken home by any.
- Cooking can happen wherever an outlet and a table is available. We used the seminar room adjacent to the foyer.
